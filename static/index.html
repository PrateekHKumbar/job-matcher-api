    System Architecture Overview

    This system is built using a decoupled architecture with a FastAPI REST backend and an SQLite relational database.
    The matching service executes text preprocessing, token normalization, and TF-IDF vectorization paired with Cosine Similarity from Scikit-Learn to evaluate candidate alignment against corporate job requirements in real-time.
